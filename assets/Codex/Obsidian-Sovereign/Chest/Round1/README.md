# Chest and torso — polish round 1

Construction study and fantasy interpretation; unskinned WIP, not fitted to the actual character.

Compared with the first pass: a convex breast and shallower back, flared waist, integral lower-plate relief, rounded opening rims with new support topology, integral attachment bosses, revised foliate inlay and darker satin steel. See REFERENCE_STUDY.md for museum sources and the limits of this interpretation.

The connected shell represents construction relief, not independently moving plates. Actual proportions, closure hardware, gorget clearance, weights, animation and Unreal import still require the source character. This is not AAA approval.
