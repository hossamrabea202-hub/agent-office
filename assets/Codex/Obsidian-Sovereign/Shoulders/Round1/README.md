# Shoulders — polish round 1

Reference-informed fantasy armour, unskinned WIP. See REFERENCE_STUDY.md for the actual museum sources, applied changes and construction limits.

For the shoulders: a deeper open wrap, taller main plate, four integral lower-lame bands, differentiated front/rear coverage, rounded borders, attachment bosses, rosette and foliate inlay. Each side is a connected closed shell. The relief is integral; the plates do not articulate independently. Nominal radial wall separation is 2.25 mm and normal thickness varies with slope. Character fit and raised-arm clearance remain unverified.
