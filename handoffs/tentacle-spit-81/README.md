# #81 Tentacle spit — BPC_TentacleSpit (DONE in the master editor, 2026-10-28)

New ActorComponent `/Game/CastleDefender/Gameplay/Tentacle/BPC_TentacleSpit`, attached to `BP_TentacleVitals` (component name `TentacleSpit`). Blueprint-only; graph generated by `tools/master/t81/gen81_v7.py` (paste file `BPC_TentacleSpit_graph_v7.txt`).

What it does
- BeginPlay: remembers root scale, binds `OnTakeAnyDamage` → `OnTentacleHit`.
- Every non-cannonball hit: short jelly wobble (0.8 s squash/stretch on the root), `HitCount++`.
- Every `SpitEvery` (3) hits, at most once per `SpitCooldown` (4 s): spawns 2 `BP_JellyBlob` in a 300–600 cm ring around player 0 (+250 cm up, random yaw). Each blob gets `ArmedMax` = 3–6 s → it lobs itself, lands, and hatches a jelly zombie (+ jelly shield) on its own.
- Spawning near the attacker (not under the tentacle) is deliberate: the tentacle vitals sit inside the huge tentacle meshes, so any trace there starts penetrating.

Verified in Simulate: 3 direct `OnTentacleHit` calls → 2 blobs at player+250 → both hatched `BP_Zombie_C` + `BP_ZombieJellyShield_C` within ~30 s. Anim rates of the hatched zombies were 1.17 / 0.99 (#72 desync working).

Tuning: `SpitEvery`, `SpitCooldown` on the component; ring radius/height are literals in the graph (Dist1/Dist2 RandomFloatInRange 300–600, UpP +250).
